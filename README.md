# DARK-ENTRAIN

Numerical code and data for **From gravitational stirring to local gas transport: encounters with a dark matter subhalo**, by Mohsen Fathi (Universidad Central de Chile).

## Quick start

1. Download the repository and keep all files together.
2. Install compatible Python dependencies with `pip install -r requirements.txt` (Python 3.8 or newer). Numba is optional.
3. Open `DARK_ENTRAIN_REPRODUCE.ipynb` in that directory and run its single cell. It automatically checks and extracts the eight simulation archives and writes a results ZIP in the same directory. No manual extraction of the inner archives is needed.

## Repository contents

- `CP29_SOURCE.py`, `CP36_RUN.py`, `recovery_fast.py`: hydrodynamic solver, main pair runner and optional compiled backend.
- `CP37_ANALYZE.py`, `CP38_KINEMATICS.py`, `CP38_PLOT.py`, `CP39_JOINT_CHECK.py`, `CP40_VERIFY.py`, `CP46_DIAGNOSTICS.py`, `CP46_VALIDATE.py`, `CP46_PLOT.py`: analysis, particle benchmark, validation and plot scripts, visible directly in GitHub. The notebook executes these in dependency order.
- `CP*.csv`, `CP*.json`, `original_DM*.csv`, `GRID.npz`: main diagnostic tables and inputs. The `earlier__` files are selected archived numerical results, not additional runs executed by the notebook.
- Eight `DM0_data_*.zip` and `DM1_data_*.zip` files contain the complete 42 saved fields from the matched control and principal 100 Myr encounter, plus configuration, final restart states and flux histories. These are the only ZIP files in the repository. Times in filenames are relative to passage. Snapshots contain `U` (density, radial momentum, tangential momentum, energy and tagged density), `x` and `y` (cell edges in pc), `t` (Myr), `phase`, `dm`, `dm_x` and `dm_y`. See the solver for units; weight the tag by cell area.
- `SHA256SUMS.txt`: SHA-256 checksums of the released files.

For manual execution, copy the Python scripts and small input tables to a working directory and unpack the four DM0 and four DM1 archives into `full_DM0` and `full_DM1`, respectively. Create a `manuscript` directory for plots generated by the scripts. Run the analysis scripts in the order listed in the notebook. The notebook uses the visible release scripts and inputs when present, checking that they match its embedded copies; a notebook downloaded alone retains its fresh-run mode.

## Scope

The release reproduces selected numerical diagnostics and plots for the principal experiment. It includes supporting outputs from earlier experiments but does not rerun every experiment in the paper. The model addresses finite-time gas redistribution in two dimensions, not permanent inward migration or the isolated effect of cooling. A full fresh hydrodynamic evolution and execution on macOS Catalina have not been tested as part of this release. Additional simulation outputs are available from the corresponding author upon reasonable request.
